## 👋 About Me

I'm a **Senior Full-Stack and AWS Integration Engineer** with **14+ years of contracting experience** (building software since 2001), delivering scalable, cloud-native and serverless systems for insurance, banking, defence, travel, media and pharma.

My day-to-day centres on **TypeScript / Node.js (10+ yrs)**, **Python / FastAPI**, **SQL & NoSQL databases (11+ yrs)** and **AWS serverless & data engineering**, with infrastructure as code in **Terraform** and **AWS CDK**. I also build **RAG and agentic AI** systems with LangChain, LangGraph and Amazon Bedrock.

- 🔧 Event-driven integration on **EventBridge · SNS · SQS · Step Functions**
- 📊 Data pipelines with **PySpark on AWS Glue**, **Apache Iceberg / Parquet** and **Athena**
- 🔐 Secure APIs: **OAuth 2.0 · OIDC · JWT · RBAC · OWASP**
- 🧪 Quality-first delivery: **Pytest · Jest · Playwright · WireMock · SonarQube**
- 🎓 Preparing for **AWS Certified Generative AI Developer – Professional**

## 🚀 Highlight Project

### NEXUS: Production Multi-Domain RAG Platform
`Python` · `LangGraph` · `Amazon Bedrock` · `FAISS / pgvector` · `RAGAS` · `LangSmith`

- 8-node **LangGraph** agentic pipeline serving four domains (healthcare, legal, fintech, cybersecurity) from one codebase, using **Claude on Amazon Bedrock** and Titan embeddings
- Advanced retrieval: contextual retrieval, HyDE, hybrid BM25 + vector search with Reciprocal Rank Fusion, cross-encoder reranking and query decomposition
- **Self-RAG** critic loop, per-domain **RAGAS** quality gates in CI/CD and LangSmith tracing for latency and cost
- Pydantic structured outputs, Gradio UI for Hugging Face Spaces
